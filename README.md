
El objetivo de este proyecto es diseñar y configurar una base de datos para una agencia de viajes ficticia, implementada en Oracle Autonomous Database dentro de Oracle Cloud Infraestructura, que nos ayuda a almacenar y gestionar la información de forma estructurada y segura.

La base de datos busca ayudar al manejo de la información relacionada con los clientes, empleados, servicios turísticos y otros datos necesarios para la agencia. Con esto se quiere reducir la duplicación de datos, mantener toda la información con un mejor orden y a la vez mejorar las consultas y gestionar los registros.

Durante el desarrollo de esta base de datos, se analiza la necesidad de la agencia y se diseña la estructura de la base de datos, incluyendo las tablas, relaciones, llaves y restricciones. También se incluye la configuración de usuarios, roles y permisos, así como el ingreso de datos y la utilización de instrucciones SQL para administrar y consultar.

En conjunto, este proyecto permite aplicar los conocimientos recibidos en este curso, sobre el diseño, la implementación y la administración de bases de datos de una manera práctica, ya que ayuda a tener la información organizada.
